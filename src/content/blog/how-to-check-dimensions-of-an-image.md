<h2 id="1-what-are-image-dimensions">1. What Are Image Dimensions?</h2>

In digital photography and design, **image dimensions** describe the physical width and height of an image measured in **pixels**.

A **pixel** (short for *picture element*) is the smallest individual dot of color that makes up a digital screen. If you zoom in extremely close to any digital photo, you will see that the picture is actually made of thousands or millions of tiny colored squares arranged in a grid like a mosaic.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                       WHAT ARE IMAGE DIMENSIONS?                        │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│      ◄───────────────────── WIDTH (Pixels) ─────────────────────►       │
│     ┌───────────────────────────────────────────────────────────┐ ▲     │
│     │                                                           │ │     │
│     │                                                           │ │     │
│     │                       DIGITAL IMAGE                       │ │     │
│     │                                                           │ H     │
│     │                                                           │ E     │
│     │                                                           │ I     │
│     │                                                           │ G     │
│     │                                                           │ H     │
│     │                                                           │ T     │
│     │                                                           │ │     │
│     └───────────────────────────────────────────────────────────┘ ▼     │
│                                                                         │
│     Format: WIDTH × HEIGHT (e.g., 1920 × 1080 pixels)                   │
└─────────────────────────────────────────────────────────────────────────┘
```

### The Golden Rule of Writing Dimensions: Width Comes First!

Whenever you see image dimensions written anywhere on the internet or in software, **the width is always written first, followed by the height**:

$$\text{Dimensions} = \text{Width} \times \text{Height}$$

* **Width:** How wide the image is from left to right.
* **Height:** How tall the image is from top to bottom.

For example, when a website asks for an image that is **1920 × 1080 pixels**, it means:
* **1,920 pixels wide** (from left to right)
* **1,080 pixels tall** (from top to bottom)

<h2 id="2-image-dimensions-vs-image-file-size">2. Image Dimensions vs. Image File Size</h2>

One of the most common points of confusion for beginners is mixing up **image dimensions** with **file size**. 

These two measurements describe completely different things:

```
┌─────────────────────────────────────────────────────────────────────────┐
│               IMAGE DIMENSIONS  vs.  IMAGE FILE SIZE                    │
├───────────────────────────────┬─────────────────────────────────────────┤
│ Image Dimensions              │ Image File Size                         │
├───────────────────────────────┼─────────────────────────────────────────┤
│ • Measured in **Pixels (px)** │ • Measured in **KB, MB, or GB**         │
│ • Example: 1920 × 1080 px     │ • Example: 450 KB or 4.2 MB             │
│ • Describes **visible size**  │ • Describes **storage space**           │
│   (how wide and tall it is)   │   (how heavy the file is on your disk)  │
│ • Controls how it looks on a  │ • Controls how fast it downloads        │
│   screen or web page          │   and how much storage it uses          │
└───────────────────────────────┴─────────────────────────────────────────┘
```

### Why Can Two Images with the Same Dimensions Have Different File Sizes?
Imagine two photos that are both **1920 × 1080 pixels**:
* **Image A** is a solid plain white background saved as a JPEG. Its file size might be just **50 KB**.
* **Image B** is a highly detailed landscape photo of a colorful forest with millions of leaves, saved as an uncompressed PNG. Its file size might be **5 MB (5,000 KB)**.

Both images have the **exact same dimensions (1920 × 1080)**, but Image B has a much larger **file size** because it contains vastly more complex color detail.

Why do websites and apps care so much about dimensions? Why can't you just upload any photo anywhere?

Here are the main reasons why checking image dimensions is essential:

<h2 id="4-how-to-check-image-dimensions-on-windows">4. How to Check Image Dimensions on Windows</h2>

Checking an image's dimensions on a Windows computer takes less than 10 seconds. You do not need any special software installed.

### Method 1: The Quick Properties Window (Most Detailed)

```
[Right-Click Image] ──► [Select Properties] ──► [Click Details Tab] ──► [Read Dimensions]
```

1. Open **File Explorer** and find the folder where your image is saved.
2. **Right-click** on the image file.
3. In the pop-up menu that appears, click **Properties** at the very bottom.
4. In the Properties window, click on the **Details** tab at the top.
5. Scroll down to the **Image** section:
   * **Dimensions:** Shows the full size (e.g., `1920 x 1080`).
   * **Width:** Shows the width in pixels (e.g., `1920 pixels`).
   * **Height:** Shows the height in pixels (e.g., `1080 pixels`).
6. Click **OK** to close the window.

### Method 2: The Fast Hover Tooltip
Simply move your mouse cursor over the image file in File Explorer and hold it still for two seconds. A small white tooltip box will appear displaying the **Item type, Dimensions, and Size**.

<h2 id="5-how-to-check-image-dimensions-on-mac">5. How to Check Image Dimensions on Mac</h2>

On macOS, finding an image's pixel dimensions is equally fast and simple.

### Method 1: The "Get Info" Keyboard Shortcut

```
[Select Image in Finder] ──► [Press Command + I] ──► [Expand "More Info"] ──► [Read Dimensions]
```

1. Open **Finder** and locate your image.
2. Click once on the image file to highlight it.
3. Press **Command + I** on your keyboard (or right-click / two-finger tap and choose **Get Info**).
4. In the Info window that opens, look for the **More Info** section.
5. Look at the **Dimensions** row: it will display the width and height (e.g., `1920 × 1080`).

### Method 2: Using the Built-In Preview App
Double-click the image to open it in **Preview**. Press **Command + I** (or click *Tools &rarr; Show Inspector*). The General Info inspector will show the exact Image Size in pixels.

```
[Open Photos App] ──► [Tap Image] ──► [Tap the "i" Info Icon] ──► [View Megapixels & Dimensions]
```

4. An information panel will slide up showing:
   * The camera model and lens used.
   * The file format (e.g., HEIC or JPEG).
   * The resolution in megapixels (e.g., `12 MP`).
   * The exact pixel dimensions (e.g., `4032 × 3024`).

<h2 id="10-landscape-portrait-and-square-images">10. Landscape, Portrait, and Square Images</h2>

The relationship between an image’s width and height determines its **orientation** (shape). All digital images fall into one of three basic shapes:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         THE 3 IMAGE ORIENTATIONS                        │
├─────────────────────────┬─────────────────────────┬─────────────────────┤
│ 1. Landscape            │ 2. Portrait             │ 3. Square           │
├─────────────────────────┼─────────────────────────┼─────────────────────┤
│ ┌─────────────────────┐ │ ┌─────────┐             │ ┌─────────────┐     │
│ │                     │ │ │         │             │ │             │     │
│ │   Width > Height    │ │ │ H > W   │             │ │   W == H    │     │
│ │                     │ │ │         │             │ │             │     │
│ └─────────────────────┘ │ └─────────┘             │ └─────────────┘     │
│ Example: 1920 × 1080    │ Example: 1080 × 1350    │ Example: 1080 × 1080│
│ (Widescreen, YouTube)   │ (Instagram Vertical)    │ (Classic Grid Post) │
└─────────────────────────┴─────────────────────────┴─────────────────────┘
```

### 1. Landscape (Horizontal)
* **Width is greater than Height** (wider than it is tall).
* **Examples:** YouTube thumbnails, desktop computer monitors, banners, movie screens.

### 2. Portrait (Vertical)
* **Height is greater than Width** (taller than it is wide).
* **Examples:** Instagram Reels, TikTok videos, smartphone full-screen wallpapers, book covers.

### 3. Square
* **Width and Height are identical**.
* **Examples:** Profile avatars, classic Instagram posts, product catalogue thumbnails.

<h2 id="12-what-if-the-image-dimensions-are-wrong-resizing-vs-cropping">12. What If the Image Dimensions Are Wrong? (Resizing vs. Cropping)</h2>

If you check your photo and discover the dimensions do not match what your website or platform requires, you have two primary options: **Resizing** or **Cropping**.

Understanding the difference between these two actions is vital:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     RESIZING  vs.  CROPPING                             │
├───────────────────────────────┬─────────────────────────────────────────┤
│ Resizing an Image             │ Cropping an Image                       │
├───────────────────────────────┼─────────────────────────────────────────┤
│ • Changes the pixel count of  │ • Cuts away and removes outer parts of  │
│   the **entire photo**        │   the photo to change its shape         │
│ • Keeps all visual content in │ • Discards unwanted edges (top, bottom, │
│   the frame                   │   or sides)                             │
│ • Scales the picture up or    │ • Adjusts the framing or orientation    │
│   down proportionately        │   (e.g., turns a landscape into square) │
└───────────────────────────────┴─────────────────────────────────────────┘
```

### When to Resize:
Use resizing when your photo already has the right shape (e.g., it is a landscape rectangle) but is simply **too large** (e.g., 4000 × 2250 px) and you want to scale it down to **1920 × 1080 px** so it loads faster.

### When to Crop:
Use cropping when your photo is the **wrong shape** (e.g., you have a tall vertical photo of yourself, but LinkedIn requires a 1:1 square profile picture). Cropping lets you cut off the left, right, or background to create a clean square without squashing your face. <h2 id="13-image-dimensions-and-aspect-ratio">13. Image Dimensions and Aspect Ratio</h2>

You will often hear image dimensions mentioned alongside **Aspect Ratio**.

**Aspect Ratio** is simply the proportional relationship between the width and height of an image, written as two numbers separated by a colon (e.g., `16:9` or `1:1`).

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    COMMON ASPECT RATIOS IN PIXELS                       │
├───────────────┬───────────────────────────────┬─────────────────────────┤
│ Aspect Ratio  │ Common Pixel Dimensions       │ Best Known For          │
├───────────────┼───────────────────────────────┼─────────────────────────┤
│ **16:9**      │ 1920 × 1080 px, 1280 × 720 px │ YouTube, HDTV, Laptops  │
│ **1:1**       │ 1080 × 1080 px, 500 × 500 px  │ Instagram Square, Logos │
│ **4:5**       │ 1080 × 1350 px                │ Instagram Portrait Feed │
│ **9:16**      │ 1080 × 1920 px                │ TikTok, Stories, Shorts │
│ **4:3**       │ 1024 × 768 px, 800 × 600 px   │ Standard Photo Prints   │
└───────────────┴───────────────────────────────┴─────────────────────────┘
```

Aspect ratio describes the **shape**, while dimensions describe the **exact pixel size**. 
* An image that is `1920 × 1080` and an image that is `1280 × 720` have different dimensions, but they have the **exact same 16:9 aspect ratio shape**.

### What does 1920 × 1080 mean?
It means the image is 1,920 pixels wide and 1,080 pixels tall. This is the standard Full HD widescreen 16:9 format.

### How can I change the dimensions of an image?
You can change dimensions by **resizing** the image (scaling the pixel resolution) or **cropping** the image (trimming outer edges to fit a new shape) in any standard photo editor.
