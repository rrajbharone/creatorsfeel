## Core Standards

See [.agents/AGENTS.md](file:///c:/Users/rrajb/Downloads/creatorsfeel.com/.agents/AGENTS.md) for permanent workspace rules:
- Mobile-first development (320px to 1920px).
- Website speed, PageSpeed, and Core Web Vitals are top priorities from the start.
- Keep Astro implementations lightweight: minimal JS, zero render-blocking resources, optimized fonts, AVIF/WebP images.
- Follow the approved design system (light/dark themes, professional SVGs, zero emojis).
- Target mobile Lighthouse Performance 90+ and FCP/LCP near 1.5s.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
